What the labels mean

{{template "shame-badge" "verified"}}
User agent matched a known crawler and the source address passed that vendor's published verification. Only these rows show individual IPs.
{{template "shame-badge" "unverifiable"}}
User agent claims a known crawler whose vendor publishes no verification method we could find. Not confirmed.
{{template "shame-badge" "spoofed"}}
User agent claimed a known crawler, but the source address failed that vendor's published verification. Shown under the network it came from, not the name it claimed.
{{template "shame-badge" "anonymous"}}
No known crawler user agent. Attributed only to the network (ASN).

Networks other than verified crawlers are shown as a /24 (IPv4) or /48 (IPv6) at most. Windows (24h, 7d, 30d) count raw requests; "all" also includes daily summaries of older traffic. Listing here states what our logs show and nothing more.
